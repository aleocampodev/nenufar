02 — State Diagrams lifecycles

Left: Order lifecycle (the money). Right: Bot conversation lifecycle (the free LLM loop). Both persist in Postgres; neither costs per-token beyond Groq free tier.

Order State

stateDiagram-v2
  [*] --> Draft: cart created
  Draft --> Pending: submitOrderAction()\n(payload.create)
  Pending --> Pending: Telegram send fails\n(order still saved)
  Pending --> Confirmed: Shirley /confirmar\n(payload.update)
  Pending --> Cancelled: Shirley cancels
  Confirmed --> Shipped: Shirley ships\n(WhatsApp coord)
  Confirmed --> Cancelled: buyer no-show
  Shipped --> [*]
  Cancelled --> [*]

  note right of Pending
    Telegram HTML sent
    to TELEGRAM_CHANNEL_ID
    Idempotent: sha256(cart+phone)
  end note
  note right of Confirmed
    Only Shirley via
    /admin or bot
    (never buyer)
  end note

Bot Conversation State (Claude Agent SDK loop)

stateDiagram-v2
  [*] --> Idle: Telegram webhook idle
  Idle --> Auth: POST /telegram/webhook
  Auth --> Rejected: chat_id != ADMIN\n→ 200 ignore
  Rejected --> [*]
  Auth --> Dedup: chat_id == ADMIN
  Dedup --> Ignored: update_id seen\n→ 200
  Ignored --> [*]
  Dedup --> Thinking: route to Agent SDK
  Thinking --> ToolCall: LLM chooses tool
  ToolCall --> ToolResult: payload.find/update\n(Postgres)
  ToolResult --> Thinking: feed result to LLM\n(max 4 rounds)
  Thinking --> Reply: LLM final text
  Reply --> Sent: sendTelegramReply(chatId)
  Sent --> [*]
  Thinking --> Error: Groq timeout
  Error --> Sent: fallback reply\n\"try again 💜\"

  note right of ToolCall
    Free: SDK → LiteLLM :4000
    → Groq Llama 3.3
    ANTHROPIC_BASE_URL trick
  end note
Why two states? Order state is business-critical and survives bot failures. Bot state is ephemeral (in-memory Set for dedup, max 1000 update_id) — safe to lose, order is already in Postgres.

Buyer never sees Telegram or LLM. Idempotency prevents double-submit. Telegram failure does not block buyer.

04 — Sequence Diagram · Shirley Bot (Option A Free) interaction via LiteLLM → Groq

End-to-end for Shirley's message "pon el collar luna en 3". Every LLM hop is free: SDK thinks it talks to Anthropic, LiteLLM translates to Groq.

sequenceDiagram
  actor Shirley as 💜 Shirley (Telegram)
  participant TG as Telegram Bot API
  participant WH as POST /telegram/webhook
Next.js
  participant SDK as Claude Agent SDK
query() + tools
  participant Lite as LiteLLM Proxy :4000
(self-hosted, free)
  participant Groq as Groq API
llama-3.3-70b (free tier)
  participant DB as PostgreSQL
Payload Local API

  Shirley->>TG: "pon el collar luna en 3"
  TG->>WH: POST /telegram/webhook
X-Telegram-Bot-Api-Secret-Token + Update{update_id, chat_id, text}
  WH->>WH: verify secret → check chat_id==ADMIN?
→ dedup update_id
  alt not Shirley
    WH-->>TG: 200 ignored
  else is Shirley
    WH->>SDK: runShirleyAgent(text, {payload, chatId})
    SDK->>Lite: POST /v1/messages (Anthropic format)
ANTHROPIC_BASE_URL=http://litellm:4000
tools: [buscarProducto, actualizarInventario...]
    Lite->>Lite: translate Anthropic → OpenAI
drop_params (strip output_config)
    Lite->>Groq: POST /openai/v1/chat/completions
{model: llama-3.3, tools, messages}
    Groq-->>Lite: {tool_calls:[{name:actualizarInventario, args:{slug: collar-luna, stock:3}}]}
    Lite-->>SDK: {content:[{type:tool_use, name:actualizarInventario}]}
    SDK->>DB: payload.update({collection:products, where:{slug:collar-luna}, data:{stock:3}})
    DB-->>SDK: {ok, stock:3}
    SDK->>Lite: tool_result → Groq (round 2)
    Lite->>Groq: POST /openai/v1/chat/completions (with result)
    Groq-->>Lite: {content: "Listo Shirley, collar Luna en 3 💜"}
    Lite-->>SDK: final text
    SDK-->>WH: reply string
    WH->>TG: sendTelegramReply({chatId: Shirley, text: reply})
    TG-->>Shirley: "Listo Shirley, collar Luna en 3 💜"
  end

  Note over SDK,Groq: $0 — Groq free tier, LiteLLM ~50MB self-hosted
Drop-in replacement: change config.yaml → paid Claude if you scale
Free guarantee: GROQ_API_KEY is consumed by LiteLLM, not by Anthropic. Set ANTHROPIC_BASE_URL=http://litellm:4000 (inside Docker: http://litellm:4000) and ANTHROPIC_MODEL=nenufar-bot. No sk-ant-* needed.
