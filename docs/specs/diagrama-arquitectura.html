Nénufar · Ruta de aprendizaje — Claude Agent SDK

Del notificador al concierge multiagente

Un mapa para aprender construyendo: el mismo bot de Telegram crece en tres etapas sobre el Claude Agent SDK — ① agente + herramientas, ② RAG con pgvector, ③ multiagente con subagentes. Cada etapa suma un concepto sin rehacer lo anterior.

⚠︎
El Agent SDK necesita un proceso de larga vida (levanta un subproceso claude con estado en disco), así que no corre en el serverless de Vercel: mientras aprendés, lo corrés local o en un contenedor barato (Fly.io / Railway). El edge de Vercel sigue siendo el que recibe el webhook y reenvía. Poné un límite de gasto en la consola de Anthropic y acotá con maxTurns.

Aprendés: embeddings, retrieval y grounding (respuestas con fundamento).

Multiagente

El orquestador delega en subagentes especializados (AgentDefinition): catálogo, pedido, gestión. Fan-out en lotes chicos.

Aprendés: delegación, subagentes, orquestación y el patrón del artículo de Anthropic.
