Bot brain — Claude Agent SDK (TypeScript · it manages the skills)

Migration target
Programming
Agent execution loop. Receives Shirley's message, decides, calls tools, processes results, repeats until done — built in, not hand-rolled. Supersedes the slice-1 orchestrator + runtime + groq.ts.
Model
Groq (Llama), free — reached via a LiteLLM proxy that bridges the SDK's Anthropic API to Groq's OpenAI format (ANTHROPIC_BASE_URL → proxy). No Claude, no per-token bill.
Extension
Skills (semantic trigger) · Subagents (task delegation) · Hooks (event trigger). The skills are Shirley's actions — the SDK is what runs them:

Integration
MCP → Payload (official @payloadcms/plugin-mcp) so skills call typed CMS tools · local tools (embeddings, Telegram reply) · headless mode for scripts.
Memory
CLAUDE.md multi-level (Enterprise → User → Project → Rules → Local) for durable rules · Supabase conversation memory for the multi-turn thread.

How it stays free: the SDK speaks the Anthropic API, so a LiteLLM proxy bridges it to Groq (free Llama). Trade-offs: an extra proxy to run, Groq is less tuned for the SDK than Claude, and it's an unofficial path (mitigate the param issue with drop_params). The core order flow doesn't depend on the bot.

Payload as MCP tools — the SDK's Integration layer

Planned · 3.4

CMS over MCP

Payload's official @payloadcms/plugin-mcp exposes the CMS as typed MCP tools (listProducts, updateStock…). The Agent SDK consumes them, so skills call safe typed tools instead of raw payload.find / update — no MCP to build from scratch.

01

An order comes in

  1. Compradora submits the cart on the web
  2. submitOrderAction saves the Order in Payload
  3. A structured message is sent to Telegram
  4. Shirley reads it, closes the sale on WhatsApp
02

Shirley manages in the admin

  1. Opens /admin in the browser
  2. Edits products, media, blog, orders
  3. Payload writes straight to PostgreSQL
03

Shirley manages by bot

  1. Messages the bot: "confirm order 42"
  2. Webhook checks her chat_id
  3. The Claude Agent SDK picks the skill
  4. Skill updates Payload (via MCP), bot replies
